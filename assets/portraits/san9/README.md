# 《三国志9》头像素材

本目录保存完整的本地头像集，运行游戏时不需要访问外部图片服务。

- 共 836 张 240×240 JPG：原版 `No_001.jpg`–`No_786.jpg`，威力加强版追加 `No_pk_001.jpg`–`No_pk_050.jpg`。
- 镜像来源：[renmu123/koei_san_character_img](https://github.com/renmu123/koei_san_character_img)，原始图站为 san.nobuwiki.org。
- 编号核对依据：2003 年《三国志IX 顔グラ交換ツール》所附 `s9face.tbl`（[存档](https://web.archive.org/web/20040816085714id_/http://ita-ken.hp.infoseek.co.jp/s9face003.lzh)），以及 [kaodata-re 的三国志9文件分析](https://github.com/tzengyuxio/kaodata-re/blob/master/notes/san9.md)。
- `No_NNN` 对应游戏内部头像编号 `NNN - 1`；`No_pk_NNN` 对应 `785 + NNN`。当前武将映射见 `src/portrait.js`。

头像原作者及版权归属光荣特库摩；镜像仓库未附带素材再发布授权，公开或商用发布前需另行确认授权。
